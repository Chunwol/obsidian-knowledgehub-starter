# 선택 플러그인

스타터는 기본 플러그인만으로 작동합니다. 아래 항목은 기존 KnowledgeHub에서 사용하는 선택 기능입니다.
옵시디언 Settings → Community plugins에서 직접 설치하고 활성화하세요.

| 이름 | ID | 용도 |
| --- | --- | --- |
| Homepage | homepage | 시작할 때 홈 노트 열기 |
| Smart Connections | smart-connections | 관련 노트 제안 |
| Advanced Tables | table-editor-obsidian | 표 편집 |
| Quick Switcher++ | darlal-switcher-plus | 노트 전환 |
| Update time on edit | update-time-on-edit | 수정 시간 관리 |

Homepage는 홈 노트로 `홈`을 선택하세요. Smart Connections의 모델·실행 방식은 설치 버전과 PC에 맞춰 확인하세요.
플러그인 버전, 모델, 계정과 API 키는 자동으로 설정하지 않습니다. 임베딩 캐시는 새 보관함에서 생성합니다.
