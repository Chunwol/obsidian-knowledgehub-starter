# Obsidian KnowledgeHub Starter 배포 설계

## 목적
기존 KnowledgeHub의 구성과 기록 방식을 다른 사람이 자신의 정보로 시작할 수 있는 GitHub 스타터로 제공한다. 원본 보관함은 수정하지 않는다.

## 저장소와 소개
- 제안 이름: `obsidian-knowledgehub-starter`.
- 한국어 README: 자체 SVG 배너, 주요 기능, 3단계 시작 안내, 폴더 구조, 사용 예시, AI 연결 방법, 문제 해결.
- 배포 ZIP과 소스 저장소를 함께 제공한다.
- 저장소 공개 여부는 사용자 확인 후 설정한다.

## 공유 보관함
- Inbox, Projects, Areas, Resources, Archive, Daily, Sessions, Conversations, Decisions, Templates, System, Attachments 구조.
- 새로 작성한 홈, 빈 프로필, 가상 예시 프로젝트, 프로젝트·일일 기록·세션·결정 템플릿.
- 필요한 기본 Obsidian 설정 및 Bases 보기.
- 기존 개인 노트, 대화, 계정 정보, 검색 DB, 임베딩 캐시, 플러그인 개인 설정은 포함하지 않는다.
- 커뮤니티 플러그인은 설치 안내를 제공한다. 외부 플러그인 코드를 무단으로 재배포하지 않는다.

## 자동 세팅
- Windows PowerShell 진입점 `setup.ps1`.
- 저장 경로와 표시 이름을 매개변수 또는 대화형 입력으로 받는다.
- 기본 경로는 사용자 Documents 아래 KnowledgeHub이며 기존 비어 있지 않은 폴더는 거부한다.
- 대상 폴더에 스타터를 복사하고 프로필을 작성하며 완료 후 여는 방법을 안내한다.
- 설치 대상 경로를 포함한 AI 시작 지침 파일을 생성한다. 기존 Codex/Claude 전역 설정은 변경하지 않는다.
- 실행 정책은 영구 변경하지 않는다. Obsidian과 Python 설치는 필수/선택 여부 및 설치 링크로 안내한다.

## AI와 도구
- 범용 AI_START.md와 복사 가능한 Codex/Claude 지침.
- Python 표준 라이브러리 기반 노트 검색, 공유용 맥락 내보내기, ZIP 백업.
- 개인 PC 경로와 특정 계정에 의존하지 않는다. AI 연결은 사용자가 해당 도구에 지침을 등록해야 한다.

## 검증
- 임시 경로에 실제 설치 후 한글 이름, 공백 경로, 설정 JSON과 링크를 확인한다.
- 기존 파일이 있는 대상에 설치를 거부하고 원본을 보존하는지 확인한다.
- 검색, 맥락 내보내기, 백업을 실제 실행한다.
- Git 추적 파일에서 개인 이름·경로·토큰 패턴 및 불필요한 원본 데이터 포함 여부를 점검한다.
- GitHub 업로드 후 원격 저장소, README와 배포 파일 존재를 확인한다.

## 완료 기준
다른 사람이 README를 따라 보관함을 만들 수 있고 자동 세팅 및 도구 검증이 통과하며, 지정 GitHub 저장소에 소스와 배포 ZIP이 올라간 상태.
