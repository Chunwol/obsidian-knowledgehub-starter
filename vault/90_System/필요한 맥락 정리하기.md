# 필요한 맥락 정리하기

과거 대화와 자료를 전부 요약하기보다 지금 필요한 프로젝트부터 정리합니다.

1. 현재 프로젝트와 필요한 질문 하나를 고릅니다.
2. 관련 자료·세션·결정만 찾아 읽습니다. 원문은 보존합니다.
3. 사용자 진술, 당시 보고, 실제 확인한 결과를 구분합니다.
4. 현재 요약에는 목표·최근 근거·다음 행동을, 해결법에는 원인·재사용 조건을 남깁니다.
5. 읽지 않은 자료를 검토 완료로 표시하지 않습니다.

자동 수집·이전 대화 검색 DB는 포함하지 않습니다. 가져온 대화는 선택해서 `65_Conversations`에 보관할 수 있습니다.
