# 작업 시작과 종료

## 시작할 때
홈에서 한 프로젝트를 고르고 다음 행동·막힌 이유·근거를 읽습니다. 실제 작업 환경이 기록과 같은지 확인합니다.

## 끝낼 때
1. [[세션 템플릿]]으로 `60_Sessions/YYYY-MM-DD-HHmmss-주제.md`를 만듭니다.
2. 관련 프로젝트의 project_id와 wiki 링크를 적습니다.
3. 확인한 결과와 미확인 범위를 구분합니다.
4. 프로젝트 속성과 **이어서 작업하기** 요약을 함께 갱신합니다. 이전 출처와 결정은 보존합니다.
5. 다시 쓸 해결 경험은 [[해결법 템플릿]], 장기 선택은 [[결정 템플릿]]으로 연결합니다.

| 속성 | 넣을 값 |
| --- | --- |
| workflow_state | 진행 / 확인 필요 / 보류 / 완료 |
| next_action | 다음에 할 구체적인 행동. 완료하면 빈 문자열 |
| blocker | 필요한 입력·선행 조건·보류 사유. 없으면 빈 문자열 |
| next_source | 근거 세션의 wiki 링크 |
| note_reviewed | 근거를 읽고 요약을 갱신한 날짜 |
| review_state | 기록 연결 확인 / 확인 필요 |
| last_verified | 실제 환경을 검증한 날짜. 기록만 읽었다면 갱신하지 않음 |

진행이면 홈의 이어할 일에, blocker가 있으면 막힌 일에 표시됩니다.
확인 필요이거나 기록 검토일이 없거나 14일 넘게 지났다면 상태 점검에 나타납니다.
기존 status는 결과를 설명하는 문구로 유지할 수 있습니다.

## AI에게 요청할 때
> 이번 작업을 세션에 기록하고 프로젝트의 다음 행동·막힌 이유·근거·검토일과 본문 요약을 함께 갱신해줘. 직접 확인한 결과와 과거 기록은 구분해줘.

조회만 요청했거나 기록을 원하지 않는 경우에는 기록하지 않습니다. [[AI 연결하기]]
