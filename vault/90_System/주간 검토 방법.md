# 주간 검토 방법

일주일에 한 번 10~15분 정도 검토합니다.

1. [[주간 검토 템플릿]]으로 `90_System/주간 검토/YYYY-Www.md`를 만듭니다.
2. [[상태 점검.base]]에서 이번 주에 볼 프로젝트를 세 개까지만 고릅니다.
3. 최신 근거를 읽고 다음 행동·막힌 이유·검토일을 갱신합니다.
4. 끝난 일은 완료, 미뤄둔 일은 보류로 표시하고 이유를 남깁니다.
5. [[빠른 메모]]에서 계속 쓸 내용을 프로젝트나 자료로 옮겨 연결합니다.
6. 재사용할 해결 경험 하나를 골라 증상·적용 조건·검증·근거를 정리합니다.
7. 다음 주 첫 행동을 남기고 검토한 항목만 완료 처리합니다.

백업 여부와 복원본 열기·검색 확인 날짜도 적습니다. 백업 ZIP은 비공개 기록을 포함하므로 개인적으로 보관하세요.
