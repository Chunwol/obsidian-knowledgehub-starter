# 시작하기

1. [[홈]]을 엽니다. 원하면 즐겨찾기에 추가하세요.
2. [[나의 프로필]]을 자기 정보로 채웁니다.
3. [[예시 프로젝트]]를 참고해 프로젝트 노트를 만듭니다.
4. `Ctrl+P`에서 Templates: Insert template을 선택합니다.
5. 작업 결과는 세션으로, 오래 기억할 선택 이유는 결정으로 남깁니다.

| 폴더 | 넣을 내용 |
| --- | --- |
| 00_Inbox | 아직 분류하지 않은 메모 |
| 10_Projects | 끝나는 목표가 있는 일 |
| 20_Areas | 계속 관리할 생활·업무 영역 |
| 30_Resources | 다시 볼 자료 |
| 40_Archive | 마무리된 자료 |
| 50_Daily | 하루 기록 |
| 60_Sessions | 작업 결과와 근거 |
| 65_Conversations | 직접 선택해서 보관한 대화 |
| 70_Decisions | 선택과 이유 |
| 80_Templates | 문서 틀 |
| 90_System | 사용법과 도구 |
| 99_Attachments | 이미지·PDF |

빠른 열기 `Ctrl+O` · 전체 검색 `Ctrl+Shift+F` · 명령 팔레트 `Ctrl+P`.
