# AI 연결하기

옵시디언 보관함을 만들었다고 AI가 자동으로 읽지는 않습니다.

## 로컬 파일을 읽을 수 있는 AI 도구
자동 세팅이 만든 보관함 최상위 `AI-INSTRUCTIONS.txt`의 내용을 복사해 사용 중인 도구의 작업 지침에 넣습니다.
Codex 프로젝트의 `AGENTS.md`, Claude Code 프로젝트의 `CLAUDE.md` 등에 기존 내용을 보존하면서 추가할 수 있습니다.
보관함 이동 시 지침의 경로도 수정하세요. 도구의 파일 접근 권한이 있어야 합니다.

## 파일 첨부를 사용하는 채팅
[[도구 사용법]]의 export로 맥락 파일을 만들고 직접 검토해서 필요한 채팅에 첨부합니다.
`privacy: shareable`로 표시한 노트만 포함됩니다. 민감정보가 없다는 보장은 아니므로 내용을 확인하세요.

다른 채팅으로의 영구 기억, 자동 업로드, 자동 대화 수집은 제공하지 않습니다.
